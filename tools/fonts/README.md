# Noto Sans KR

The unmodified variable font `NotoSansKR-Variable.ttf` is Noto Sans KR from
the official Google Fonts repository. It provides exact Korean glyphs for
the code-rendered clinical guide diagrams.

License: SIL Open Font License 1.1. The complete copyright and license text
is retained in `OFL-NotoSansKR.txt`. Source URLs, downloaded file sizes and
SHA-256 hashes are recorded in `font-source.json`.

The renderer uses local files only. It does not download a font, access a
network service or require a paid image-generation API when generating
guide assets.
