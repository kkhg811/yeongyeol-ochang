청주·오창 손목건초염

오창 손목 건초염 평가에서는 엄지 쪽 손목 힘줄 경로의 통증·부종과 일상 동작을 연결합니다. 드퀘르벵과 다른 손목·손가락 질환의 범위를 구분한 뒤 검사와 관리 목적을 설명받으세요.

  2. 02 · 원인·배경 살피기

    최근 손목과 엄지 사용이 바뀌었나요?

  3. 03 · 진찰·검사 준비

    진찰은 어떤 질문을 확인하나요?

    통증 위치와 힘줄 움직임, 엄지 관절·신경 문제를 어떻게 구분하는지 물어보세요.

  4. 04 · 치료·상담 선택

    힘줄 부담을 어떻게 줄이나요?

    엄지를 벌리고 손목을 꺾어 드는 방식 대신 편안한 대체 동작을 배웁니다.

  5. 05 · 생활에서 관리하기

    육아와 도구 사용에서 바꿀 점은 무엇인가요?

    아기를 들 때 손끝만으로 받치기보다 팔 전체로 지지할 방법을 문의하세요.

  6. 06 · 변화·재평가 확인

    경과는 어떤 과제로 비교할까요?

    컵 들기·옷 입히기 등 실제 불편한 과제와 다음 날 통증 반응을 기록하세요.
