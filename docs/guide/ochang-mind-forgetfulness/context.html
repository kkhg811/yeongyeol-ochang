전체 가이드 ↗
  1. 01 · 증상·대상 확인

    어떤 종류의 깜박함인가요?

    물건을 둔 곳이나 약속을 잊는지, 같은 질문을 반복하는지와 힌트를 받으면 떠오르는지를 예로 적습니다.

  2. 02 · 원인·배경 살피기 · 읽는 중

    기억이 나빠지는 원인은 하나일까요?

    수면 부족, 우울·불안, 약물·음주와 신체 질환이 기억 또는 주의에 영향을 줄 수 있습니다.

  3. 03 · 진찰·검사 준비

    진료에 무엇을 가져갈까요?

    언제부터 시작됐고 점점 심해지는지, 실제 안전 문제나 경제적 실수가 있었는지 기록합니다.

  4. 04 · 치료·상담 선택

    평가 뒤 어떤 도움을 받나요?

    확인된 원인에 맞춰 수면·기분·약물·신체 문제를 조정하고 필요한 전문 진료를 연결합니다.

  5. 05 · 생활에서 관리하기

    일상의 안전을 어떻게 지킬까요?

    일정·복용·물건 위치를 한 가지 방식으로 정리하고 필요한 경우 신뢰할 사람과 확인 체계를 만듭니다.

  6. 06 · 변화·재평가 확인

    어떤 변화를 다시 알려야 하나요?

    기억뿐 아니라 말·판단·성격·보행과 일상 독립성이 달라지는지 시간에 따라 확인합니다.

02 · 원인·배경 살피기

기억이 나빠지는 원인은 하나일까요?

건망증은 주의를 기울이지 못했거나 잠·기분 상태가 나쁠 때도 생길 수 있지만 생활에 영향을 주는 변화는 평가가 필요합니다. 나이나 깜박한 횟수만으로 치매를 단정하지 않고 이전과 달라진 기능과 경과를 살핍니다.
